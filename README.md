# file-converter

Convertidor y compresor de imágenes en el navegador (Next.js).

## Requisitos

- Node.js 20+
- [Yarn](https://yarnpkg.com/) (Classic 1.x). Con Node 16+ puedes activar Corepack: `corepack enable` y usar la versión fijada en `package.json` (`packageManager`).

## Instalación

```bash
yarn install
```

## Desarrollo

```bash
yarn dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Otros comandos

```bash
yarn build
yarn lint
```

## Dependencias nuevas

Usa siempre Yarn, por ejemplo:

```bash
yarn add nombre-paquete
```

No uses `npm install` en este proyecto.
